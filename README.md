## 🧪 Selected projects

> **Anti-Viral Drug Design Using Model-Based Reinforcement Learning and Generative Models**
> An AI framework in Python that combines model-based reinforcement learning with generative models to explore and score candidate antiviral molecules, aiming for safe, drug-like candidates in a search space too large for manual or trial-and-error methods.

> **Enhanced MAC Protocol for Efficient Collision Resolution in IEEE 802.11 Networks**
> A modification of the IEEE 802.11 MAC collision-resolution logic so nodes skip the DIFS wait whenever the backoff period already exceeds it. Modeled in a simulated wireless network of 6 mobile nodes, where the modified protocol resolved collisions with less idle wait time than the standard protocol.
